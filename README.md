# Operaciones con enteros en Java

Ejercicio de consola que pide dos números enteros y calcula su suma, resta, multiplicación, división entera y resto.

Si el segundo número es cero, muestra un mensaje en lugar de intentar la división o el módulo.

## Ejecución

Necesitas un JDK 11 o superior y el comando `java` disponible en la terminal. Desde la carpeta del proyecto:

```sh
java OperacionesEnteros.java
```

Introduce cada número y pulsa Enter. Por ejemplo, con 7 y 3 se obtiene:

```text
Suma: 10
Resta: 4
Multiplicacion: 21
Division (cociente entero): 2
Modulo (resto): 1
```

La división es entera: descarta la parte decimal. El programa espera entradas válidas de tipo `int` y utiliza la aritmética entera de Java.
